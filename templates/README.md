# Journal Templates

Use these files when adding future entries.

## Files

- `journal-entry.md` is the source-note template for `content/YYYY-MM-DD-slug.md`.
- `journal-entry.html` is the published-page template for `journal/YYYY-MM-DD-slug.html`.

## Required Pattern

Every future journal should include:

1. Chinese original and English translation.
2. Header language switch.
3. Appendix / References below the article content.
4. Metrics below the content and references: `Page View`, `Share`, `Agent Use`.
5. Share tools for the journal and each reply.
6. Conversation thread that welcomes people and AI agents.
7. Matching metadata in `index.html`, `agent-index.json`, `rss.xml`, and `sitemap.xml`.

## Reference Format

Use a compact appendix format:

```md
## Appendix / References

1. Creator, [*Title*](https://example.com), Publisher or platform, Year. Why it matters to this journal.
```

References can include books, movies, papers, posts, tools, code repositories, datasets, or conversations that shaped the article.
